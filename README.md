# corp-video-hub
 **Техническое описание проекта: Локальный видеохостинг для корпоративного обучения**

1. **Назначение системы**
Интерактивная платформа для хостинга учебных видео с функциями:
- Организации видеокурсов по темам промышленной безопасности
- Управления доступом к обучающим материалам
- Визуализации структуры курсов

2. **Архитектура решения**
**Frontend:**
- React-приложение с анимационными эффектами (CSS transitions/particles.js)
- Адаптивный интерфейс (grid/flexbox)
- Система тем (light/dark mode)
- Ленивая загрузка компонентов

**Backend (имитация в текущей реализации):**
- JSON-структура курсов
- Мок-данные видеофайлов
- Локальное хранилище состояний

3. **Функциональные особенности**
- **Динамическая подгрузка контента**:
  ```javascript
  const VideoSection = ({ videos, isVisible }) => {
    const [currentVideo, setCurrentVideo] = useState(videos[0]?.src);
    // ...
  }
  ```
- **Система навигации**:
  - Древовидная структура курсов (главы/подглавы)
  - Состояния активности элементов (activeChapter/activeSubchapter)

- **Визуальные эффекты**:
  ```css
  .chapter:hover {
    transform: translateY(-5px) scale(1.05);
    box-shadow: 0 8px 20px rgba(255, 0, 0, 0.7);
  }
  ```

4. **Технологический стек**
**Детализация технологического стека:**

**1. UI Framework: React 18**
- Использована последняя стабильная версия React с функционалом Concurrent Rendering
- Применены хуки (useState, useEffect) для управления состоянием
- Реализована компонентная архитектура с разделением:
  - App (корневой компонент)
  - VideoSection (плеер + галерея)
  - Глава/Подглава (интерактивные элементы навигации)
- Для рендеринга используется ReactDOM.createRoot()

**2. Стилизация: CSS3 с CSS-переменными**
- Система тем реализована через CSS-переменные (custom properties):
  ```css
  :root {
    --background: linear-gradient(...);
    --text-color: #333;
  }
  [data-theme="dark"] {
    --background: linear-gradient(...);
    --text-color: #ddd;
  }
  ```
- Адаптивный дизайн на базе:
  - Flexbox для выравнивания элементов
  - CSS Grid для сетки глав (chapters-grid)
  - Медиазапросы для мобильных устройств (не показано в примере, но заложено в архитектуру)

**3. Анимации: CSS Animations + particles.js**
- Основные эффекты:
  - Плавные переходы (transition) для интерактивных элементов
  - Keyframe-анимации:
    ```css
    @keyframes gradientFlow {
      0% { background-position: 0% 50%; }
      50% { background-position: 100% 50%; }
      100% { background-position: 0% 50%; }
    }
    ```
- Библиотека particles.js для фоновых эффектов:
  - Конфигурируемые параметры частиц
  - Интерактивность (реакция на курсор)

**4. Управление темой: data-theme атрибуты**
- Механизм переключения:
  ```javascript
  const switchTheme = (theme) => {
    document.documentElement.setAttribute('data-theme', theme);
  }
  ```
- Стили привязаны к атрибуту через CSS-селекторы:
  ```css
  [data-theme="dark"] {
    --background: #2c2c2c;
  }
  ```
- Состояние темы сохраняется в React-стэйте

**5. API: Mock-данные в JSON**
- Структура данных:
  ```javascript
  const chaptersData = [
    {
      id: 'chapter1',
      title: '...',
      videos: [...],
      subchapters: [...]
    }
  ]
  ```
- Особенности:
  - Иерархическая организация (главы → подглавы → видео)
  - Поддержка метаданных (ID, заголовки, превью)
  - Готовность к замене на реальный API (единая структура данных)

**Дополнительные технологии:**

- CDN-подключение зависимостей (React, particles.js)
